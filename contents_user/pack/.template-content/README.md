# Шаблоны материалов

Готовые `pack.md` для каждого типа материалов: все поля, теги и описание состава. Сайт эту папку не читает: он показывает только паки из `Semples/`, `Presets/`, `Projects/` и `Collection/`.

## Как пользоваться

1. Скопируй папку шаблона в нужный раздел и переименуй её (латиница, строчные буквы, дефисы: `Heavy Drums Vol 1` → `heavy-drums-vol-1`):

   | Шаблон                   | Куда копировать                  | Что это                            |
   | ------------------------ | -------------------------------- | ---------------------------------- |
   | `Semples/sample-pack/`   | `contents_user/pack/Semples/`    | сэмплы: драмы, лупы, one-shots, FX |
   | `Presets/preset-bank/`   | `contents_user/pack/Presets/`    | пресеты синтезаторов и эффектов    |
   | `Projects/daw-project/`  | `contents_user/pack/Projects/`   | проект DAW со стемами и MIDI       |
   | `Collection/collection/` | `contents_user/pack/Collection/` | набор из нескольких паков, бандл   |

2. Заполни `pack.md`. Всё в `[квадратных скобках]` — заглушки. Обязательны `title` и `date`, остальное можно удалить.
3. Положи рядом `cover.jpg` (или `.png`, `.webp`) — квадрат от 1200×1200. Без неё сайт подставит шаблонную обложку.
4. Сам архив в репозиторий не кладут: залей его на Boosty, Patreon, Ko-fi или в облако и вставь ссылку в `download`.
5. Поставь `draft: false`. Пока стоит `true`, пак виден только в `npm run dev`.

## Что видно на карточке

| Поле                      | Где                                                                |
| ------------------------- | ------------------------------------------------------------------ |
| `title`                   | название                                                           |
| `count`, `bpm`, `key`     | строка под названием: «120 сэмплов · 140–150 BPM · F minor»        |
| `price`                   | плашка «Бесплатно» или цена                                        |
| `license`                 | плашка «Лицензия Free / Standard / Extended» со ссылкой на условия |
| `genre`, `format`, `tags` | чипы; теги участвуют в поиске по сайту                             |
| `download`                | кнопка «Скачать» у бесплатного пака, «Приобрести» — у платного     |

Текст после `---` (описание и состав) на карточке пока не выводится: он пригодится для отдельной страницы пака.

## Лицензии

| `license`  | Когда                                         | Условия                                   |
| ---------- | --------------------------------------------- | ----------------------------------------- |
| `free`     | бесплатные паки                               | [free.md](../../licenses/free.md)         |
| `standard` | подписка Boosty или Patreon, покупка на Ko-fi | [standard.md](../../licenses/standard.md) |
| `extended` | покупка с правом синхронизации                | [extended.md](../../licenses/extended.md) |

Без поля `license` бесплатный пак получает Free, платный — Standard.

Все поля — в [CONTENT.md](../../../Git-And-Docks/RU-ru/CONTENT.md).
