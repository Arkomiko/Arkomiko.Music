# Шаблоны релизов

Готовые `release.md` со всеми полями и подсказками. Сайт эту папку не читает: он смотрит только в `traks/RLS/` и `traks/DR/`. В репозитории папка есть, хотя сами треки в git не попадают.

## Как пользоваться

1. Выбери шаблон и скопируй его папку целиком:
   - релиз или пред-релиз — в `contents_user/traks/RLS/`;
   - черновик или техно-демка — в `contents_user/traks/DR/`.
2. Переименуй папку: это адрес страницы. Латиница, строчные буквы, дефисы: `My New Track` → `my-new-track`.
3. Заполни `release.md`. Всё в `[квадратных скобках]` — заглушки. Ненужные поля удали: обязательны только `title` и `date`.
4. Положи в папку:
   - `tracks/01-<папка>.mp3` — аудио; у альбома `01-…`, `02-…` по порядку;
   - `cover.jpg` (или `.png`, `.webp`) — квадратная обложка от 1200×1200. Без неё сайт подставит шаблонную.
5. Поставь `draft: false`. Пока стоит `true`, релиз виден только в `npm run dev`.
6. Проверь: `npm run check`, затем страницу `/release/<папка>` в `npm run dev`.

## Шаблоны

| Папка             | Куда копировать | Для чего                                                             |
| ----------------- | --------------- | -------------------------------------------------------------------- |
| `RLS/single/`     | `RLS/`          | сингл через дистрибьютора: UPC, лейбл, все площадки, блок «О релизе» |
| `RLS/album/`      | `RLS/`          | альбом или EP: несколько треков, свои названия и BPM для каждого     |
| `RLS/prerelease/` | `RLS/`          | пред-релиз: дата в будущем, без скачивания                           |
| `RLS/cover/`      | `RLS/`          | кавер: автор оригинала, ограничения лицензии                         |
| `RLS/remix/`      | `RLS/`          | ремикс чужого трека с разрешением автора                             |
| `RLS/label/`      | `RLS/`          | релиз через лейбл: условия лейбла вместо Arkomiko Music License      |
| `DR/techno-demo/` | `DR/`           | техно-демка или черновик: CC BY-NC-SA 4.0                            |

## Лицензия по умолчанию

| Что                                 | Лицензия               |
| ----------------------------------- | ---------------------- |
| `kind: techno-demo` или папка `DR/` | CC BY-NC-SA 4.0        |
| всё остальное                       | Arkomiko Music License |

Поле `license` в `release.md` перекрывает значения по умолчанию: можно поменять одно поле или все. Тексты лицензий — в [`../../licenses/`](../../contents_user/licenses/).

Все поля и значения — в [CONTENT.md](CONTENT.md).
