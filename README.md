# arkomiko.music

Сайт с музыкой Arkomiko: релизы, техно-демки, обложки. Собран на [Astro](https://astro.build) + Vue (плеер).

## Запуск

Нужен Node.js 22 или новее.

**В VS Code:** открой папку проекта, согласись установить рекомендованные расширения (Astro, Vue, Prettier, YAML), выполни `npm install` в терминале и нажми **F5** («Сайт: dev-сервер») — сервер запустится и откроет браузер. Форматирование при сохранении уже настроено.
Другие стартеры в панели «Запуск и отладка»: «dev-сервер в сети (телефон)», «собрать и посмотреть», «astro check». Если `node_modules` нет, `npm install` выполнится сам.

Или из терминала:

```bash
npm install      # один раз
npm run dev      # локальный сайт на http://localhost:4321, обновляется при сохранении
npm run build    # готовый сайт в папке dist/
npm run preview  # посмотреть собранный dist/ локально
```

## Как добавить релиз

1. Создай папку в `releases/`. Имя папки = адрес страницы: `releases/cold-memories` → `/releases/cold-memories`.
   Только латиница, строчные буквы и дефисы. После публикации папку не переименовывай, иначе сломаются ссылки.
2. Положи в неё:
   - `cover.jpg` (или `.png` / `.webp`), квадрат, лучше от 1200×1200;
   - `tracks/` с mp3. Порядок треков — по имени файла, поэтому начинай с номера: `01-intro.mp3`, `02-...`;
   - `release.md` с описанием (пример ниже).
3. Сохрани — релиз появится на главной, в каталоге и в обложках.

Название и длительность трека сайт берёт из тегов mp3. Если тегов нет — из имени файла без номера.

```yaml
---
title: Cold Memories
date: 2026-03-14
type: single # single | ep | album
links: # любые из: spotify, apple, yandex, vk, youtube, youtubeMusic, soundcloud, bandcamp, deezer
  spotify: https://...
  yandex: https://...
license: # необязательно; без него — лицензия по умолчанию
  name: © Arkomiko, дистрибуция FreshTunes
  url: https://... # необязательно
download: false # true — под каждым треком появится «Скачать mp3»
accent: '#9cc3ff' # необязательно; без него цвет берётся из обложки
credits:
  - 'Музыка: Arkomiko'
draft: true # необязательно; черновик виден только в npm run dev
---
Описание релиза в Markdown.
```

## Как добавить демку

То же самое, только в папке `demos/`. Поля `type` нет. Если демка потом вышла релизом, укажи имя папки релиза:

```yaml
released_as: cold-memories
```

На странице демки появится ссылка на релиз, а на странице релиза — «Ранние версии».
Папки в `releases/` и `demos/` могут называться одинаково, конфликта не будет.

## Что где лежит

```
releases/, demos/          контент: по папке на релиз
src/site.config.ts         имя, соцсети, лицензии по умолчанию, подписи площадок
src/styles/global.css      цвета, шрифты, общие стили (токены в начале файла)
src/content.config.ts      какие поля бывают в release.md
src/lib/media.ts           чтение обложек, mp3, тегов и цвета обложки при сборке
src/stores/player.ts       общее состояние плеера (nanostores)
src/components/Player.vue  плеер внизу экрана, не прерывается при переходах
src/components/PlayButton.vue   кнопки «Слушать» на страницах
src/components/*.astro     карточки, списки, страница релиза
src/pages/                 страницы сайта (адрес = путь к файлу)
```

## Публикация

Проще всего через **Cloudflare Pages**: подключи GitHub-репозиторий, команда сборки `npm run build`, папка `dist`. Сайт будет пересобираться при каждом пуше. Потом там же подключается домен arkomiko.music.

## Про большие файлы

GitHub не принимает файлы больше 100 МБ, и репозиторий с кучей аудио быстро разрастается. Для сайта хватает mp3 (192–320 kbps). WAV/FLAC для скачивания лучше хранить отдельно (например, в Cloudflare R2) и давать ссылкой.
