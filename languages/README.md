# Языки сайта

Каждый файл здесь — один язык. Сайт сам находит файлы, добавляет язык в переключатель в шапке и собирает страницы `/<код>/…`.

В репозитории — только готовые переводы: русский и английский. Заготовки остальных языков хранятся локально, пока не переведены (правило в `.gitignore`); готовый язык публикуется строкой-исключением там же.

| Файл         | Язык               | Адреса        | Состояние                                                  |
| ------------ | ------------------ | ------------- | ---------------------------------------------------------- |
| `RU-ru.ts`   | русский — основной | `/`, `/music` | заполняется автором                                        |
| `EN-en.ts`   | английский         | `/en/…`       | переведён                                                  |
| остальные 57 | см. списки ниже    | `/<код>/…`    | заготовки, перевода пока нет; в репозиторий не выгружаются |

## Как это устроено

- **Шаблон — [`src/i18n.ts`](../src/i18n.ts).** В нём все элементы интерфейса: ключ (`nav.music`) и подсказка на английском в квадратных скобках — где элемент стоит на сайте и что в него писать. Новый элемент сначала появляется там.
- **Перевод — файл языка.** В блоке `ui` те же ключи, но с готовым текстом. Порядок ключей не важен, лишних быть не может: опечатку в ключе покажет `npm run check`.
- **Нет перевода — видна подсказка.** Если ключа нет в файле языка, на сайте выводится подсказка из шаблона в `[квадратных скобках]`. Так сразу видно, что осталось перевести.
- **Неполный язык не индексируется.** Пока переведены не все ключи, страницы языка закрыты от поисковиков (`noindex`) и не указываются в `hreflang`.

## Как перевести язык

1. Открой файл языка, например `DE-de.ts`.
2. Скопируй строки с ключами из `EN-en.ts` или `RU-ru.ts` в блок `ui` и замени текст.
3. Сохрани `{n}` и `{name}` — это подстановки числа и названия.
4. Проверь: `npm run check`, затем страницу `/<код>` в `npm run dev`.

Формы множественного числа — ключи `count.*.one`, `few`, `many`, `other`. Какие формы есть в языке, подсказывает [Intl.PluralRules](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules): в английском — `one` и `other`, в русском — `one`, `few`, `many`. Если нужной формы нет в файле, берётся `other`.

Подпись в подвале (`footer.credit`, `footer.creditLink`) обязательна по лицензии кода: переводить можно, убирать нельзя.

## Как добавить или убрать язык

- **Добавить** — создать файл по образцу любой заготовки: `XX-xx.ts`, где `xx` — код языка ISO 639-1, а если его нет — ISO 639-3 (`HSB-hsb.ts`). Поля: `code` (префикс адреса), `locale` (даты и числа), `name` (название на самом языке — так он виден в переключателе), `nameEn` (для сортировки), `dir: 'rtl'` для письма справа налево.
- **Убрать** — удалить файл. Страницы языка пропадут при следующей сборке.
- Основной язык (`ru`) задан в `src/lib/locale.ts`, его файл удалять нельзя.

Три группы: 30 самых распространённых языков мира, все живые славянские и все живые романские (произошедшие от латыни) языки — с письменной нормой и официальным или признанным статусом. Русский, французский, итальянский, испанский и португальский входят сразу в две группы и записаны один раз.
