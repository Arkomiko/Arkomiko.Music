# contents_user

Весь контент сайта. Код его только читает — добавлять и менять можно без программирования.

```
traks/RLS/<папка>/   релизы и пред-релизы   → раздел «Музыка», страница /release/<папка>
traks/DR/<папка>/    черновики              → раздел «Музыка», страница /release/<папка>
pack/Semples/<папка>/     сэмплы            → раздел «Материалы»
pack/Presets/<папка>/     пресеты
pack/Projects/<папка>/    проекты
pack/Collection/<папка>/  коллекции
licenses/*.md        тексты лицензий (позже — окно для чтения на сайте)
```

В папке трека: `release.md` (описание), `tracks/01-название.mp3` (аудио), `cover.jpg` (необязательно).
В папке материала: `pack.md`, `cover.jpg` и `preview.mp3` (необязательно).
Нет обложки — сайт сам подставит шаблонную и закрепит её за папкой. Чтобы выбрать шаблон вручную, укажи `placeholder: 3`.
Поля описаны в README.md (рядом).
