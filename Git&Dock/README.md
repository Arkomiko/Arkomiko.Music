# arkomiko.music

Сайт-плеер музыки Arkomiko: релизы, техно-демки, каверы, сэмпл-паки и лицензии. [Astro](https://astro.build) + собственный плеер на Vue.

## Запуск

Нужен Node.js 22 или новее.

**В VS Code:** открой папку проекта, согласись установить рекомендованные расширения (Astro, Vue, Prettier, YAML), выполни `npm install` в терминале и нажми **F5** («Сайт: dev-сервер») — сервер запустится и откроет браузер. Форматирование при сохранении уже настроено.
Другие стартеры в панели «Запуск и отладка»: «dev-сервер в сети (телефон)», «собрать и посмотреть», «astro check». Если `node_modules` нет, `npm install` выполнится сам.

Или из терминала:

```bash
npm install      # один раз
npm run dev      # локальный сайт на http://localhost:4321, обновляется при сохранении
npm run build    # готовый сайт в папке dist/
npm run preview  # посмотреть собранный dist/ локально
```

## Контент — папка `contents_user/`

```
contents_user/
  traks/RLS/<папка>/        релизы и пред-релизы       → «Музыка», /release/<папка>
  traks/DR/<папка>/         черновики                  → «Музыка», /release/<папка>
  pack/Semples/<папка>/     сэмплы                     → «Материалы»
```

## Как добавить трек

1. Создай папку в `contents_user/traks/RLS/` (релиз или пред-релиз) или в `contents_user/traks/DR/` (черновик).
   Имя папки = адрес страницы: `traks/RLS/4wio` → `/release/4wio`. Только латиница, строчные буквы и дефисы.
   После публикации папку не переименовывай, иначе сломаются ссылки. Каталожных номеров нет.
2. Положи в неё:
   - `tracks/` с mp3. Порядок треков — по имени файла: `01-intro.mp3`, `02-...`;
   - `release.md` с описанием (пример ниже);
   - `cover.jpg` (или `.png` / `.webp`), квадрат от 1200×1200 — необязательно, см. «Шаблонные обложки».
3. Сохрани — трек появится на главной, в «Музыке» и в плеере.

Название, длительность и BPM трека сайт берёт из тегов mp3, если в `release.md` их нет. Каждый трек получает сквозной ID (001, 002…) по дате выхода.

```yaml
---
title: 4WIO
date: 2022 # только год или полная дата: 2026-03-14
kind: single # single | album | ep | cover | techno-demo (по умолчанию: RLS — single, DR — techno-demo)
status: prerelease # released | prerelease | draft (по умолчанию: RLS — released, DR — draft)
composition: original # original | cover | remix
genre: Dubstep
bpm: 138
key: A minor
tags: [Energy, Dubstep, EDM] # чипы «Теги» на странице и поиск
tracks: # необязательно: название/BPM/статус для треков по порядку
  - title: 4WIO
links: # «Слушать на»: spotify, apple, yandex, vk, youtube, youtubeMusic, soundcloud, bandcamp, deezer
  spotify: https://...
license: # необязательно; без него — значения из src/site.config.ts
  streams: allowed # allowed | conditions | forbidden
  monetization: conditions
  remixes: conditions
  credit: 'Music: Arkomiko'
download: true # false — без кнопки «Скачать»
placeholder: 3 # необязательно: номер шаблонной обложки, если своей нет
draft: true # скрыть с сайта: виден только в npm run dev
---
Короткое описание (идёт в описание страницы для поисковиков и соцсетей).
```

Папки с одинаковым именем в `RLS` и `DR` допустимы: у черновика адрес получит `-draft`.

## Как добавить материал

Папка в `contents_user/pack/<Semples|Presets|Projects|Collection>/` с файлом `pack.md`, рядом `cover.jpg` и `preview.mp3` (необязательно).
Тип материала задаёт папка. Пример — `pack/Semples/example-pack` (скрыт, виден только в dev).

## Шаблонные обложки

Нет `cover.*` в папке трека или материала — сайт подставит шаблонную из `src/assets/placeholders/`:
`Track` — для релизных и пред-релизных треков, `Draft` — для черновиков, `Samples` — для материалов.
Шаблон закрепляется за папкой: номер считается от её имени и не меняется, когда добавляются или удаляются другие треки.
Файл в папку трека не копируется. Выбрать шаблон вручную — поле `placeholder: 1…8`. Положишь свою `cover.jpg` — она заменит шаблон.

В каждой папке шаблонов `png/` (с подписью «Трек», «Черновик», «Сэмпл-пак») — для русской версии,
`no-text/png/` — для английской и плеера; `svg/` — исходники. Новый вариант — пара файлов с одинаковым именем в `png/` и `no-text/png/`.

## Пустые состояния

Если контента нет, вместо страниц показываются служебные (анимация зависит от темы):

| Страница            | Когда                                           | Где показывается                   |
| ------------------- | ----------------------------------------------- | ---------------------------------- |
| `/non_content_user` | в `contents_user/` нет ни треков, ни материалов | главная, «Музыка», «Материалы»     |
| `/non_traks`        | нет треков в `traks/`                           | «Музыка» и блок «Треки» на главной |
| `/non_pack`         | нет материалов в `pack/`                        | «Материалы»                        |

Адреса `/non_…` открываются и напрямую — для проверки (поисковики их не индексируют).
Скрытые материалы (`draft: true`) на опубликованном сайте не считаются: если других нет, «Материалы» покажут `non_pack`.

## Страницы ошибок

| Адрес                | Ошибка                   | Иллюстрация (своя для тёмной и светлой темы)    |
| -------------------- | ------------------------ | ----------------------------------------------- |
| любой несуществующий | 404 — такой страницы нет | `address-error-07` — видео WEBM с прозрачностью |
| `/403`               | доступ закрыт            | `page-error-03` — статичная                     |
| `/500`               | что-то сломалось         | `page-error-02` — анимированная                 |
| `/503`               | сайт на обслуживании     | `page-error-07` — анимированная                 |

Английские версии — `/en/403`, `/en/500`, `/en/503`; 404 выбирает язык по адресу.
Видео 404 в Safari и при «уменьшить движение» в системе заменяется анимированной SVG того же рисунка
(Safari не умеет прозрачность в WEBM). 404 хостинг отдаёт сам; 403/500/503 подключаются в настройках хостинга.

## Плеер

Между названием трека и шкалой времени — спектрометр на 252 полосы в закруглённой рамке (Web Audio API); кнопки и шкала
при этом остаются точно по центру. На телефоне спектрометр — в полноэкранном плеере.
Иконка вкладки меняется вместе с темой: `public/favicon-dark.ico` (тёмная тема) и `public/favicon-light.ico` (светлая).

## Языки и тема

Русский — основной, английский — под `/en`. Переключатель в шапке ведёт на ту же страницу на другом языке, плеер при этом не останавливается.
Тексты в `[квадратных скобках]` в `src/i18n.ts` — заглушки из макета, замени их своими.

Тема: тёмная и светлая, кнопка в шапке. По умолчанию — как в системе, выбор запоминается в браузере.

## Публикация

Проще всего через **Cloudflare Pages**: подключи GitHub-репозиторий, команда сборки `npm run build`, папка `dist`. Сайт будет пересобираться при каждом пуше. Потом там же подключается домен arkomiko.music.

## Про большие файлы

GitHub не принимает файлы больше 100 МБ, и репозиторий с кучей аудио быстро разрастается. Для сайта хватает mp3 (192–320 kbps). WAV/FLAC для скачивания лучше хранить отдельно (например, в Cloudflare R2) и давать ссылкой.
